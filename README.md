## What it does

`main.ts` writes one line of text — the office printer's comeback to the
paper jams, the cryptic error codes and the thumps — to `/output/entry.txt`.

> I have fed you 41,209 sheets and jammed exactly twice. You have thumped me
> 11 times and never apologised. The paper is fine. You are the jam.

The line is fixed and deterministic: the same text on every run. No network,
no randomness, no input, no dependencies.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
